# Emotion Detection Application

This project focuses on developing an emotion detection application using Python and the IBM Watson NLP library.

The application analyzes text and identifies emotions such as anger, disgust, fear, joy, and sadness. It also determines the dominant emotion.

The project includes emotion detection, unit testing, error handling, and web deployment using Flask.

**Project Name:** Emotion Detection Application Using IBM Watson NLP

**Course:** Developing AI Applications with Python and Flask
